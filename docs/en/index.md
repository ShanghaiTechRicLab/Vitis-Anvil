# Vitis-Anvil documentation

Vitis-Anvil is a CMake project template for forging Vitis/XRT FPGA accelerators.

Read in order if you are new:

1. [Get started](get_started.md) — run the full local flow.
2. [Accelerator-card flow](accelerator_flow.md) — U250/U50/U55C/U200/U280/VCK5000 style devices.
3. [Embedded flow](embedded_flow.md) — ZCU102/ZCU104/ZCU106/KV260 style devices.
4. [Customization](customization.md) — own kernels, host apps, devices, datasets, reports.
5. [Adapt to your project](adapt_to_your_project.md) — copy the template into real products.
6. [Development workflow](development_workflow.md) — day-to-day iteration model.
