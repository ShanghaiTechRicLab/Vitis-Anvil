# Vitis-Anvil 文档

Vitis-Anvil 是一个用于锻造 Vitis/XRT FPGA accelerator 的 CMake project template。

如果你是第一次使用，建议按顺序读：

1. [快速开始](get_started.md) — 跑完整本地流程。
2. [加速卡流程](accelerator_flow.md) — U250/U50/U55C/U200/U280/VCK5000 类设备。
3. [Embedded 流程](embedded_flow.md) — ZCU102/ZCU104/ZCU106/KV260 类设备。
4. [自定义](customization.md) — 自己的 kernel、host app、设备、数据集、报告。
5. [适配到自己的项目](adapt_to_your_project.md) — 把模板迁到真实产品。
6. [典型开发流程](development_workflow.md) — 日常迭代方式。
