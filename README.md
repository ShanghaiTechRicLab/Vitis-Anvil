# Vitis-Anvil

A CMake project template for forging Vitis/XRT FPGA accelerators.

Anvil is the iron block where hardware is forged into shape. This repository is intentionally short-named and CLI-friendly: `anvil init`, `anvil build`, and similar wrappers can map cleanly onto the Make/CMake flows documented here.
